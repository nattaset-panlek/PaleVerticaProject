PART 1: HIGH-LEVEL ARCHITECTURAL LAYERS
--------------------------------------------------------------------------------

1.1 DATA & PERSISTENCE LAYER (The Foundation)
----------------------------------------------
The source of truth for all game variables, items, and skill configurations.
- [GameData] (Static): Global accessibility point for PlayerData. Keeps the session state.
- [PlayerData]: Central hub for a player's instances (Inventory, Equipment, Skills, Character).
- [Database]: The "Bridge" between offline JSON data and Unity Assets. Clones ScriptableObjects and injects JSON values at runtime.
- [Skill/ItemDatabaseModels]: C# Structs designed for efficient JSON parsing.

1.2 CORE ENTITY SYSTEM (The Actors)
------------------------------------
Everything that lives, moves, or reacts in the world.
- [IEntity]: The contract for all interactable objects (Health, Stats, Position).
- [Character]: The base implementation for all units. Manages the lifecycle of an entity.
- [PlayerCharacter]: Extends Character with Input processing and UI hooks.
- [AttributeSystem]: The state machine for numerical values. Handles complex math for stat buffs/debuffs.

1.3 SKILL SYSTEM PIPELINE (The Actions)
----------------------------------------
The complex engine that processes player intent into visual and mechanical results.
- [SkillCaster]: Manages the "State" of rasing a skill (Idle -> Casting -> Channelling -> Recovery).
- [ActiveSkill/SkillInstance]: The definition and the runtime instance of a skill.
- [Targeting/Effect Logic]: Modular blocks that decide WHO to hit and WHAT to do.
- [VisualManager]: Orchestrates the spawning of VFX and Indicators.

1.4 UI & INTERFACE LAYER (The Representation)
----------------------------------------------
How the player communicates with the core systems.
- [UI Managers]: Singletons (Inventory, ContextMenu, DamageText) that bridge Data to Pixels.
- [Windows/Fragments]: The visual layout and individual widgets.

PART 2: THE "NERVOUS SYSTEM" (Data Flow & Events)
--------------------------------------------------------------------------------

2.1 COMMUNICATION FLOWS
1. UI Interaction: Player drags item -> UI calls [InventoryManager] -> Manager calls [EquipmentManager] -> Updates [AttributeSystem].
2. Stat Update: [AttributeSystem] changes -> Invokes [OnStatusChanged] -> [HPBarUI] / [AttributeList] refreshes.
3. Skill Casting: Controller -> [SkillCaster] check Mana -> Start [VCT/FCT Coroutine] -> Trigger [Animation] -> [ApplyEffects].
4. Damage Delivery: [EffectLogic] -> [Payload] -> Target [ReceiveDamage] -> [DamageTextManager] spawns text.

2.2 TIMING & LATENCY (Skill Lifecycle)
- VCT (Variable Cast Time): Reduced by "Casting Speed" or "DEX".
- FCT (Fixed Cast Time): Non-reducible time for balancing.
- GCD (Global Cooldown): Prevents skill spamming.

PART 3: ATOMIC SCRIPT DICTIONARY (1 to N)
--------------------------------------------------------------------------------

[--- CORE - DATA ACCESS ---]

1. GameData.cs
   - Role: The singleton-like static access point.
   - Flow: Assets/Scripts check GameData.Player to find the current active player's data.
   
2. PlayerData.cs
   - Role: Initialization hub.
   - Flow: When a game starts, it instantiates InventoryManager, EquipmentManager, and SkillManager.

3. Database.cs
   - Role: Data synchronization engine.
   - Flow: Reads Assets/Resources/Data/Skill.json -> Finds matching ScriptableObject Template -> Merges values.

4. SkillDatabaseModels.cs / ItemModels.cs
   - Role: Serialized data blueprints.
   - Flow: Used by JsonUtility to map text strings into C# variables.

[--- CORE - ATTRIBUTES & STATS ---]

5. AttributeSystem.cs
   - Role: The "Calculator".
   - Flow: Stores a Dictionary of <AttributeType, Attribute>. Recalculates stats whenever a modifier is added.

6. Attribute.cs
   - Role: Individual stat container.
   - Flow: Maintains BaseValue and a List of Modifiers (Flat/Percent).

7. AttributeModifier.cs
   - Role: A "Bonus" packet.
   - Flow: Created by Items or Buffs. Added to an Attribute to change its CurrentValue.

[--- CORE - MOVEMENT & NAVIGATION ---]

8. MovementSystem.cs
   - Role: Physics driver.
   - Flow: Receives Vector3/Path. Moves Transform. Translates Velocity to Animator parameters.

9. PathfinderGrid.cs
   - Role: World scanner.
   - Flow: Scans the scene for colliders/tiles to build a "Walkable" node map.

10. Pathfinder2D.cs
    - Role: Brain of navigation.
    - Flow: Uses A* Algorithm to calculate the optimal path of Vector3 points between two nodes.

[--- CORE - SKILL SYSTEM CORE ---]

11. SkillCaster.cs
    - Role: Execution manager.
    - Flow:
        1. CastSkill(id) starts.
        2. Check MP via AttributeSystem.
        3. Check Cooldowns.
        4. Run StartCastCoroutine.
        5. Invoke OnSkillExecuted events.

12. ActiveSkill.cs
    - Role: Skill data definition.
    - Flow: Defines ManaCost, Range, Cooldown, and links to Targeting/Effects.

13. SkillInstance.cs
    - Role: Runtime wrapper.
    - Flow: A unique "Thread" for one casting instance, preventing data overlap between multiple simultaneous skills.

14. SkillPayload.cs
    - Role: Information container.
    - Flow: Carries Calculated Damage, Element, and Source info from the Caster to the final Target.

15. OutputScaling.cs
    - Role: Damage formula modifier.
    - Flow: Scales damage based on STR/INT or Level (e.g., Damage = Base + (STR * 1.5)).

[--- SKILL SYSTEM - TARGETING LOGICS ---]

16. TargetingLogic.cs (Base)
    - Role: Logic blueprint for finding victims.

17. SingleTargeting.cs
    - Role: Point-click logic. Finds the exact IEntity under cursor or nearest target.

18. SphereAOETargeting.cs
    - Role: Radial search. Uses Physics2D.OverlapCircle to find multiple targets in a radius.

19. ConeTargeting.cs
    - Role: Directional search. Checks Angle and Distance between Caster and potential targets.

20. BoxTargeting.cs
    - Role: Rectangular search. Useful for "Dash" skills or wide cleaves.

21. SelfTargeting.cs
    - Role: Utility/Buff logic. Target is always the Caster.

22. LinePierceTargeting.cs
    - Role: Linear penetration. Uses RaycastAll to hit everything in a straight line.

23. TargetLocationTargeting.cs
    - Role: Ground-targeting. Returns a Vector3 world point instead of an IEntity.

[--- SKILL SYSTEM - EFFECT LOGICS ---]

24. EffectLogic.cs (Base)
    - Role: Logic blueprint for actions.

25. DamageEffect.cs
    - Role: Harm logic. Applies Damage Payload to target's HP.

26. HealEffect.cs
    - Role: Restoration logic. Adds value to target's HP Attribute.

27. ApplyBuffEffect.cs
    - Role: Persistent bonus. Adds a Flat/Percent modifier to a target's attribute via TemporaryBuffManager.

28. ApplyTemporaryBuffEffect.cs
    - Role: Time-limited bonus. Extends ApplyBuffEffect with duration logic.

29. MovementEffectLogic.cs
    - Role: Displacement. Forces target to Dash, Pushback, or Stun.

30. SummonObjectEffect.cs
    - Role: Instantiation. Spawns an OBJ at target location (e.g. Totem, Pet).

31. SpawnProjectileEffect.cs
    - Role: Projectile bridge. Spawns the ProjectileBehaviour game object.

[--- SKILL SYSTEM - UNIQUE MECHANICS ---]

32. TimeDilationSkill.cs
    - Role: Temporal manipulation.
    - Workflow:
        1. Mark targets in range.
        2. Snapshot Position/HP every X seconds into a List.
        3. Create Ghost Clones for visual path.
        4. On duration end: Lerp targets backward through the List of positions.
        5. Destroy Ghosts as they are "collected" by the returning target.

33. ChainLightningSkill.cs
    - Role: Sequential targeting. Finds nearest target, jumps X times with damage decay.

34. BlinkStrikeSkill.cs
    - Role: Teleport attack. Teleports caster to back of target and applies strike.

35. ParrySkill.cs
    - Role: Reactive logic. Listens for incoming DamageEffects and cancels them if active.

PART 4: THE MASTER EXECUTION LOOP (Step-by-Step)
--------------------------------------------------------------------------------

STORY: Player casts "Fireball" at an Enemy.
1. [Input] -> PlayerController detects Mouse Click.
2. [Order] -> PlayerController calls SkillCaster.CastSkill(FireballID).
3. [Check] -> SkillCaster checks Mana (AttributeSystem) and Cooldown.
4. [Sync]  -> Database.cs returns the Synchronized Fireball Asset.
5. [Preview]-> SkillIndicatorManager spawns a CircleIndicator.
6. [Charge] -> SkillCaster starts InitiateCastSequence (VCT/FCT duration).
7. [Visual] -> VisualManager spawns "Casting Flame" particle on hands.
8. [Cast]   -> Animation event triggers "Execute".
9. [Spawn]  -> SpawnProjectileEffect creates Fireball Projectile.
10.[Action] -> ProjectileBehaviour moves toward Target.
11.[Impact] -> ProjectileBehaviour.OnTriggerEnter hits Enemy IEntity.
12.[Payload]-> DamageEffect calculates DMG based on INT Scaling.
13.[Apply]  -> Enemy.AttributeSystem (HP) is reduced.
14.[Show]   -> DamageTextManager spawns a red "500" text.
15.[Clean]  -> Projectile is destroyed.

PART 5: MODULARITY & EXTENSION (How to add new things)
--------------------------------------------------------------------------------
- TO ADD A STAT: Add value to AttributeType (Enum) -> UI automatically lists it.
- TO ADD A SKILL: Create ActiveSkill SO -> Select Targeting/Effect Type -> Assign to DB.
- TO ADD A UNIQUE SKILL: Inherit from ActiveSkill -> Override Execute() -> Write custom logic.
- TO ADD AN ITEM: Create Item/Equipment SO -> Assign AttributeModifiers.
