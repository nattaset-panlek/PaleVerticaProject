## 1. แก่นเรื่อง

**Pale Vertica: Whispers of the Pale Throne**

ผู้เล่นคือ **Noname** นักเดินทางไร้นามในโลกหลังการล่มสลาย ต้องเอาตัวรอดท่ามกลางสงครามตัวแทนของเทพบรรพกาลและเทพนอกจักรวาล ผู้เล่นอาจเป็นเพียงพยานผู้บันทึกเหตุการณ์ หรือเป็นตัวแปรที่เปลี่ยนชะตาของบัลลังก์ซีดจาง

**The Severance:** โลกคือซากของอาณาจักรเอเธรานิล (Aetheranil) ที่พังทลายหลังกษัตริย์ไอล์เซนทำลายพันธสัญญาเทพ ท้องฟ้าบิดเบี้ยวเป็นสีม่วงจาง และอุณหภูมิลดต่ำผิดปกติเมื่อเข้าใกล้พลังงานโบราณ

**แนวคิดที่คำบรรยายไอเทมย้ำบ่อย:** พันธสัญญานำความสงบมาให้ แต่แลกด้วยการยอมจำนน ("the covenant was a cage") ส่วนการทำลายมันทำให้เป็นอิสระแต่เปิดทางให้สิ่งจากนอกจักรวาล

## 2. ลำดับเหตุการณ์

เรียงจากข้อมูลที่มี ยังไม่มีการกำหนดปีหรือระยะเวลา

1. **ยุค The First King:** ก่อนการทำพันธสัญญากับเทพบรรพกาล
2. **ยุคพันธสัญญา:** เทพบรรพกาลทำพันธสัญญาและมอบความสงบ แลกกับการยอมจำนน
3. **กบฏของไอล์เซน:** ราชาทำลายพันธสัญญา ใช้อาวุธทุบรูปปั้นเทพบรรพกาล
4. **The Severance:** ท้องฟ้าฉีกขาด สิ่งจากความมืดหลั่งไหลเข้ามา Alveros ยืนหยัดร่วมกับราชองครักษ์
5. **หลังการล่มสลาย:** Alveros ผูกวิญญาณไว้กับพันธสัญญาที่แตกสลาย ผู้รอดชีวิตกระจายตัวตามชายแดน
6. **ปัจจุบันของเกม:** Noname มาถึง และเห็นการตื่นของ Serina

## 6. โครงเรื่องและตอนจบ

| ช่วง | เหตุการณ์ |

| Prologue | Noname มาถึงและเห็นการตื่นของ Serina |

## 7. พลังและกฎของโลก

ทั้งหมดนี้ยังเป็น [ดีไซน์]

| ระบบ | ผล |
|---|---|
| Cosmic Corruption 25-50% | พลังโจมตีเพิ่ม แต่ Max HP ลด |
| Cosmic Corruption 75% ขึ้นไป | คนในเมืองหวาดกลัวและไม่ค้าขายด้วย |
| Cosmic Corruption 100% | Lost: Game Over หรือกลายเป็นศัตรู |
| Shadow Taint | อัญเชิญเงาบ่อยจะทิ้งรอยในวิญญาณ ทนความเย็นได้ แต่ถูกอัศวินวิญญาณตามล่าง่ายขึ้น |
| Shadow Calling | เรียกวิญญาณมาช่วยสู้ชั่วขณะ ใช้ Shadow Stones |
| Covenant Shards | ทรัพยากรที่นำกลับมาอัปเกรดตัวละคร |

**ศัตรูในเนื้อเรื่อง:** อัศวินวิญญาณแห่งเอเธรานิล (ธาตุ Ghost), Outer God Spawns (ร่างทรงเทพนอกดารา), Alveros (Boss)
