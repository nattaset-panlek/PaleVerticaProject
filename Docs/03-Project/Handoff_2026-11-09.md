# Handoff งาน Pale Vertica (2026-11-09)

สรุปสำหรับทำต่อบนเครื่องอื่น ถ้าไม่ได้เขียนว่ายืนยันแล้ว ให้ถือว่ายังไม่ได้ทดสอบ ฉบับก่อนหน้าคือ `Docs/03-Project/Handoff_2026-11-08.md`

## เริ่มงานบนเครื่องใหม่

งานรอบนี้อยู่บน branch `wip/class-quest-2026-11-09` ยังไม่ได้ merge เข้า `main`

```bash
git fetch origin
git switch wip/class-quest-2026-11-09
git submodule update --init
```

จากนั้นเปิด Unity 6 (6000.4.8f1) แล้วทำตามนี้

1. กด **Pale Vertica > UI > Build Quest Window** เพื่อเอาปุ่ม Navigation ออกจาก prefab (ดูหัวข้อ "ต้องทำก่อน")
2. กด Play แล้วลองตามหัวข้อ "ยังไม่ได้ตรวจ"

Talk to Figma ต้องเปิด plugin และ join channel `flowux` ใหม่บนเครื่องนั้น ไฟล์ช่วยรันสคริปต์ใน scratchpad เป็นของเครื่องเดิมและไม่ได้ขึ้น git

## ต้องทำก่อน

- **Prefab ยังมีปุ่ม Navigation:** โค้ดและ Figma เอาออกแล้ว แต่ `Quest Window.prefab` ใน branch นี้ยังเป็นรุ่นเก่า ปุ่มจะกดได้แต่ไม่ทำอะไรจนกว่าจะกด Build Quest Window การ Build จะสร้าง prefab ทั้ง 3 ตัวของ Quest ใหม่ทับของเดิม
- **บั๊ก Level Cap:** ที่เลเวลสูงสุด `ExperienceSystem` ได้ค่า EXP ถัดไปเป็น 0 จึงอาจวนลูปไม่จบเมื่อได้ EXP ยังไม่ได้แก้

## ยังไม่ได้ตรวจ

ตรวจแล้วเฉพาะ `compile_check.py` ผ่านทั้งสอง assembly

- Render เทียบ Figma ของ Class Select และ Quest และ layout report ใน `Logs/UIDebug` (ใช้ `Tools/FigmaToUnity/unity_batch.sh` ตอนปิด Unity)
- EditMode Tests: `PassiveClassFormulaTests`, `LevelUpPointFormulaTests`, `PlayerQuestsTrackingTests`, `SkillTreeLoaderTests`
- เล่นจริงหน้า Quest: L, X, Track/Untrack, Reject, การเลื่อนรายละเอียด, Hover และคลิกขวาที่ Reward
- Item Detail ขึ้นทับหน้า Quest ถูกชั้นหรือไม่
- สถานะ Selected ของการ์ด Class อาจหลุดตอน Confirm Dialog ขึ้น
- Esc ไม่ได้ปิดหน้า Quest แล้ว เพราะไม่ได้อยู่ใน modal stack ให้เช็กว่ารับได้หรือไม่

## ข้อควรระวังเวลาทำต่อ

- อ่าน `AGENTS.md` และ `.claude/skills/pale-vertica-dev/SKILL.md` ก่อนแก้ script งาน UI จาก Figma ตาม `.claude/skills/figma-to-unity/SKILL.md`

- VFX เป็น grayscale เท่านั้น
- MapLab ห้ามอ้างอิงโค้ดเกม และ commit ในโฟลเดอร์ของมันเอง
- หน้าต่าง Quest ใช้ธีม `UI_*` ห้ามใช้ Element ของ Global หรือ Setting
- เกมนี้ไม่มีระบบ Navigation
