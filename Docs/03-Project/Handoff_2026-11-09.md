## เริ่มงานบนเครื่องใหม่

งานรอบนี้อยู่บน `main` แล้ว (อัปเดตล่าสุด 2026-11-10 ที่ commit `619e284`)

```bash
git switch main
git pull --ff-only
git submodule update --init
```

จากนั้นเปิด Unity 6 (6000.4.8f1) กด Play แล้วลองตามหัวข้อ "ยังไม่ได้ตรวจ"

## ปิดแล้วหลังเขียน handoff รอบแรก

- **ปุ่ม Navigation:** ไม่มีใน `Quest Window.prefab` แล้ว (`b8ca239`) ไม่ต้องกด Build Quest Window อีก ถ้ากด จะสร้าง prefab ทั้ง 3 ตัวของ Quest ใหม่ทับของที่อัปเดตไว้
- **บั๊ก Level Cap:** แก้แล้ว (`6ad9596`) ลูปใน `ExperienceSystem` หยุดเมื่อ EXP ถัดไปเป็น 0 และ EXP ที่เลเวลสูงสุดถูกตั้งเป็น 0 ยังไม่มีเทสต์ครอบกรณีนี้
- **Font asset:** `619e284` แก้ TMP font asset 3 ตัว ถ้าตัวหนังสือดูเพี้ยนหลัง pull ให้กด Refresh หรือเปิด Unity ใหม่

## ยังไม่ได้ตรวจ

ตรวจแล้วเฉพาะ `compile_check.py` ผ่านทั้งสอง assembly ซึ่งรันก่อน commit `6ad9596`

- Render เทียบ Figma ของ Class Select และ Quest และ layout report ใน `Logs/UIDebug` (ใช้ `Tools/FigmaToUnity/unity_batch.sh` ตอนปิด Unity)
- EditMode Tests: `PassiveClassFormulaTests`, `LevelUpPointFormulaTests`, `PlayerQuestsTrackingTests`, `SkillTreeLoaderTests`
- เล่นจริงหน้า Quest: L, X, Track/Untrack, Reject, การเลื่อนรายละเอียด, Hover และคลิกขวาที่ Reward
- Item Detail ขึ้นทับหน้า Quest ถูกชั้นหรือไม่
- สถานะ Selected ของการ์ด Class อาจหลุดตอน Confirm Dialog ขึ้น
- Esc ไม่ได้ปิดหน้า Quest แล้ว เพราะไม่ได้อยู่ใน modal stack ให้เช็กว่ารับได้หรือไม่
