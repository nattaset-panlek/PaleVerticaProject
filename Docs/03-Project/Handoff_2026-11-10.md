## งานที่ทำในรอบนี้

### 1. Scenario Test (ระบบเทสต์ที่ AI เขียนเองได้)

| ส่วน | ที่อยู่ |
|---|---|
| ตัวรัน (อ่าน JSON แล้วส่ง Input จำลอง) | `Assets/Script/ScenarioTesting/` ครอบด้วย `#if UNITY_EDITOR \|\| PV_SCENARIO_TESTS` ไม่ติดไปกับ build |
| Action ที่เรียกจาก JSON | `Assets/Script/ScenarioTesting/Actions/` เพิ่มเองได้ด้วย `[ScenarioAction]` |
| หน้าต่าง Checklist และ batch runner | `Assets/Script/Editor/ScenarioTesting/` |
| ไฟล์ scenario | `Tests/Scenarios/` (setup, core, quests, passives, combos, chaos) |
| ผล | `Tests/Results/<agent>/<name>.json`, ประวัติทุกรอบใน `history/`, สรุปรวม `_summary.md` |
| คู่มือ | `Docs/02-Technical/Testing/PlayMode_Scenario_Walkthrough.md` |
| แผนที่ Flow ของเกม (ต้องกดอะไรก่อนถึงแต่ละระบบ) | `Docs/02-Technical/Testing/Game_Flow_Map.md` |
| กฎสำหรับ AI | `.claude/skills/playmode-scenario/SKILL.md`, agent `.claude/agents/playtester.md`, `AGENTS.md` ข้อ 5b |

ความสามารถหลัก

- ส่ง Input จำลอง: เดิน WASD, คลิกซ้าย/ขวา/ดับเบิลคลิก, ลากวาง, ปุ่มลัดหน้าต่าง, System Menu
- ผลแต่ละ check เป็น Pass, Review (รอคนตรวจ) หรือ Fail พร้อมค่าที่คาดกับค่าจริง
- Save แยกตาม agent ที่ `Saves/Profiles/<agent>/`
- `"path": ["setup/new_warrior_lv15.json"]` หรือ `{"do":"Include"}` ให้ scenario เริ่มจาก setup ร่วมกัน
- ตั้งตัวละครตามกติกาเกม: `Level`, `SpendStats`, `ChooseClass`, `AssignSkill`, `EquipItem` หรือแก้ตรง `SetBase`
- `Kill` ตายแล้วกด Revive แล้วสู้ต่อจนครบ นับใน metric `deaths`
- รันแบบไม่เปิดหน้าต่าง (ต้องปิด Unity): `Tools/FigmaToUnity/unity_batch.sh playtests:quests/`

### 2. บั๊กเกมที่แก้ (เจอจาก scenario)

| บั๊ก | แก้ที่ |
|---|---|
| Exception ทุกเฟรมเมื่อเป้า auto-attack ถูกทำลาย | `PlayerCore.ForgetDestroyedTarget` |
| Unique Passive ที่ให้ `...Percent` (MaxHP%, MoveSpeed%, ASPD%) ไม่มีผล: Hollow Crown, Whisper Pact, Skirmisher's Pace, Pack Instinct, Burden of Kings | `UniquePassive.SetBonus` ส่งต่อไปที่ stat หลักแบบเดียวกับไอเทมและ Skill Tree |
| Curse of Kanix + Eldritch Faith ได้ค่าต่างกันตามลำดับ | `UniquePassive.CoreAttributeOrder`, Curse สลับ stat ก่อนเสมอ |
| ฮีลของ Vampire ตัด HP ส่วนเกินของ Hollow Crown | `UniquePassive.RestoreResource` ไม่ลด HP ที่เกิน max |

สองข้อกลางเปลี่ยนผลการคำนวณ stat ถ้าไม่ใช่ที่ตั้งใจ ให้ย้อนได้

### 3. งานค้างจากรอบก่อนที่ขึ้นไปด้วย

- Script ของ Unique Passive 46 ตัว, hook ใหม่ใน DamageHandler/HealHandler/SkillCaster/Consumable, Notable และสมดุล stat ของ Skill Tree
- `DialogueConversation` แยก logic ออกจาก `DialogueWindow`, `SaveStorage.UseProfile`

## ยังไม่ได้ตรวจ

ตรวจแล้วเฉพาะ `compile_check.py` ผ่านทั้งสอง assembly ไม่ได้รัน EditMode tests และไม่ได้รัน scenario หลังแก้รอบล่าสุด

- รัน **Run all** แล้วอ่าน `_summary.md` ผลส่วนใหญ่ในไฟล์ตอนนี้เป็นของรอบ 16:01 ก่อน Input ใช้งานได้ (hit = 0)
- `quests/bones_on_the_road.json` เคยผ่านถึงขั้นรับเควสและเข้า Field แล้ว ขั้นเลือก Class, ใส่ Tackle บน hotbar และ Kill แบบ Revive ยังไม่เคยรัน
- `core/ui_flow.json` ใหม่ ยังไม่เคยรัน
- EditMode: `ScenarioFormatTests` (มีเทสต์ path ใหม่ 2 ตัว), `DialogueConversationTests`, `SaveProfileFormulaTests`

## สิ่งที่รู้แล้วจากการไล่ระบบ

- เกมใหม่: Tackle อยู่ในสล็อตสกิล 0 แต่ไม่ขึ้นบน hotbar UI (`SkillCaster.Initialize` ไม่เรียก `SyncHotbarSlot`) อาจเป็นบั๊กเกม ยังไม่ได้แก้
- ปุ่ม Town บนหน้าจอตายกดไม่ได้เสมอ เพราะ `PlayerCore` ไม่ส่ง callback ให้
- ตัวละครเลเวล 1 ตายใน 3 วินาทีเมื่อสู้ Skeletom ตัวแรกใน Field อาจต้องปรับสมดุล
- ปุ่ม E ผูกทั้ง Inventory และ Interact (Interact ไม่ได้ใช้)

## งานถัดไป

- รัน scenario ทั้งหมดและแก้จนไม่มี Fail
- Save ของ Entity อื่นนอกจาก Player (ตอนนี้ทำเฉพาะ Player)
