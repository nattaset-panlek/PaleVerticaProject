สรุปสำหรับทำต่อบนเครื่องอื่น ถ้าไม่ได้เขียนว่ายืนยันแล้ว ให้ถือว่ายังไม่ได้ทดสอบ ฉบับก่อนหน้าคือ `Docs/03-Project/Handoff_2026-11-10.md` (รอบนั้นใช้ branch `wip/...` ซึ่งรวมเข้า `main` และลบไปแล้ว)

## เริ่มงานบนเครื่องใหม่

```bash
git switch main
git pull --ff-only
git submodule update --init
```

เปิด Unity 6 (6000.4.8f1) แล้วทำตามนี้ครั้งเดียว

1. **Pale Vertica > Visuals > Build Direction Hint Assets** เพื่อสร้าง material และ settings ของ Direction Hint (ยังไม่เคยกดบนเครื่องไหน)
2. **Window > General > Test Runner > EditMode > Run All** (test ชุดใหม่ยังไม่เคยรันเลย ดูหัวข้อ "ยังไม่ได้ตรวจ")
3. **Pale Vertica > Testing > Scenario Checklist > Run all** ที่ speed x1

## งานที่ทำในรอบนี้

### บั๊กเกมที่แก้ (ยืนยันด้วย scenario แล้ว)

| บั๊ก | สาเหตุ | แก้ที่ |
|---|---|---|
| เกมใหม่ไม่มี Tackle ในช่องสกิลและ hotbar | prefab serialize ช่องสกิลเป็น object เปล่าที่ไม่ใช่ null | `SkillCaster.Initialize`, `HotbarManager` เติมช่องว่างของ layout เริ่มต้น |
| passive (Bone Choir ฯลฯ) พังหลังเปลี่ยน scene | handler ของ event static ค้างจากตัวละครที่ถูกทำลาย | `Character.OnDestroy` เรียก `UniquePassives.Clear()` |
| แถบเลือด HealthLocalStatus ค้างข้าม scene ไม่มีเจ้าของ | แถบอยู่ใต้ `WorldSpace` ใน `[Game Core]` และลบเฉพาะตอนตาย | `Character.OnDestroy` ลบแถบเสมอ |
| ตีตัวที่ไม่มี AI แล้วแถบเลือดไม่ขึ้น | มีแค่ `AgentHandle` ที่สั่งให้แถบขึ้น | `Character.TriggerOnTakeDamage` แสดงแถบเอง |
| ไล่ตีแล้วเดินชนเสาค้าง | ไล่เป็นเส้นตรง (`CommandMove`) | `PlayerCore.HandleAutoAttack` ใช้ `PlayerApproach` ที่หาเส้นทางด้วย `WalkableGridManager` |
| error `InvalidKeyException` ทุกครั้งที่โหลดไอคอน buff | ลอง key ที่ไม่มีก่อนเจอ key จริง | `AddressableAssetLoader.TryLoad` ใช้ใน Buff, Item, Skill icon loader |
| ภาษาที่เลือกกลับเป็น EN ทุกครั้งที่เปิดเกม | `GameSetting.Load()` ไม่เคยถูกเรียก | โหลดตอนเริ่มเกม |

### Scenario Test

- เมาส์และคีย์บอร์ดจริงถูกปิดระหว่างรัน, รอหน้าจอโหลดหายก่อนคลิก, `Approach` เดินตามเส้นทาง, จับการร่ายด้วย probe passive ของตัวรัน (`ScenarioCastProbe` ไม่ได้ลงทะเบียนกับเกม)
- หน้าต่าง Checklist: progress bar, อัปเดตหลังรันจบ, ปุ่ม **Copy** และ **Copy fails**, ล้าง History และตั้งจำนวนรอบที่เก็บ
- scenario ใหม่: `skills/every_skill`, `skills/skill_passive_combos`, `core/status_bar_scene`, `core/direction_hint`
- `combos/conflicts` และ `combos/order` ตัดความสุ่ม (regen, crit) ออกจาก scenario โดยไม่แตะ check

ผลล่าสุดบนเครื่องนี้: scenario ทุกตัวที่รันหลังแก้ผ่าน, `skills/skill_passive_combos` ผ่าน 476 ข้อ (Review 5), `core/direction_hint` ผ่าน 4 ข้อ (Review 1)
