# Refactor Log: 2026-10-15

Behaviour-preserving cleanup of the combat core, plus two bug fixes. No stat or damage formula was changed.

## Bug fixes
| Issue | Cause | Fix |
|---|---|---|
| `Bleeding` and `BloodBleeding` DoTs dealt no damage to most characters | The DoT damages its owner with `Caster = Owner`; `DamageEffect` refused because a faction is never hostile to itself (except faction 1) | Self-inflicted damage tagged with a proc id (`ProcSkillIds.BleedTick`) skips the hostility check. Other self-damage still follows faction rules. |
| `AdditionalChain` entries with the same `Order` could change order | `List.Sort` is not stable | Entries are inserted in place; equal `Order` keeps insertion order |

## Structural changes
- **Damage math** moved from `DamageEffect` into `Skills/Logic/Damage/DamageCalculator.cs` (`BuildInput` + pure `Calculate`) and `CombatStatLookup.cs`. Same operation order, same random roll usage.
- **Support modifier factory**: the 22-case switch in `SupportModifier.Create` is replaced by `[SupportModifierId(n)]` on each class, discovered by `Utile/AttributedTypeRegistry.cs`. Constructors no longer set `ID`; the factory sets it from the attribute.
- **EchoSpell (1021) / SpellCascade (1022)**: the hard-coded, duplicated logic in `SkillCaster` now lives in the modifiers via `ICastRepeater` / `IPayloadSplitter` (`Skills/SupportExecutionHooks.cs`). They use their own fields, so tooltip numbers and gameplay numbers can no longer drift apart.
- **Unique passives**: one class per file, registered with `[UniquePassiveId("...")]`. Shared helpers `DealProcDamage` and `RestoreResource` replace four copies of payload code. Magic ids -999/-998/-997 are named in `Skills/ProcSkillIds.cs`.
- **Noise / safety**: removed per-character `Debug.Log` spam from `AttributeSystem.Initialize`; `SkillTreeManager` resets its static instance and events on play-mode start.
- **Tests**: 34 EditMode tests added (all passing in Unity 6000.4.8f1 batch mode). See [Testing](../02-Technical/Testing.md).

## Not changed (needs a design decision)
- Fixed Cast Time can still be reduced by `FixedCastTimeReduc` / FCT%, which conflicts with the "immutable" rule in `AGENTS.md`.
- `Character.RecalculateStats` would apply the global `SkillTreeManager` tree to every character if that component were ever added to a scene. It is not in any scene today, and `PlayerCharacter` overrides it with `PassiveNodes`.
