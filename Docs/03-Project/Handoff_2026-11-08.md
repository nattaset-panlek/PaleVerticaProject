# Handoff งาน Pale Vertica (2026-11-08)

สรุปงานที่เปิดค้างอยู่ทั้งหมด อิงจากรายงานล่าสุดของแต่ละ session และ `git status` ณ วันที่เขียน ถ้าไม่ได้เขียนว่ายืนยันแล้ว ให้ถือว่ายังไม่ได้ทดสอบ

## สถานะรวม

- **Git:** Pale Vertica อยู่ที่ `main` commit ล่าสุด `c205990` มีไฟล์ค้างยังไม่ commit ประมาณ 920 รายการ งานทุกข้อด้านล่างยังไม่ได้ commit
- **MapLab:** เป็น repo แยกที่ `Assets/ThirdParty/MapLab` (origin `https://github.com/nattaset-panlek/MapLab.git`, commit `73bf3ea`) มีไฟล์ค้าง 1 ไฟล์คือ `Editor/MapLabMapEditor.cs`
- **Unity MCP:** เลิกใช้แล้ว ถอด `com.unity.ai.assistant` ออกจาก `Packages/manifest.json` แล้ว เวลา Unity เปิดอยู่ให้แก้ไฟล์บนดิสก์ แล้วให้ผู้ใช้กด Refresh, รันเทสต์ และเช็ก Play mode เอง ใช้ batch mode ได้เฉพาะตอน Unity ปิด
- **การ compile:** ผู้ใช้ยืนยันว่า compile, เทสต์ และ Play mode ผ่านในงานแก้ซูมกล้อง งานที่แก้หลังจากนั้น (ร้านค้า) รายงานว่า compile ผ่าน แต่ยังไม่ได้รันเทสต์

## ค้างจากก่อนหน้านี้ ยังไม่ได้ตรวจ

- Play mode ของ ASPD, DoubleAttack/DoubleSpell, Echo, Fire Bolt, VisualManager และ indicator
- สีไอคอนและ backplate ของ Hotbar
- การถอด `com.unity.ai.assistant` ยังไม่มีการยืนยันจากผู้ใช้ว่า error `connection.state_change` หายแล้ว

## ข้อควรระวังเวลาทำต่อ

- อ่าน `AGENTS.md` และ `.claude/skills/pale-vertica-dev/SKILL.md` ก่อนแก้ script
- ห้าม commit หรือ push ถ้าผู้ใช้ไม่ได้สั่ง และงาน MapLab ต้อง commit ในโฟลเดอร์ของมันเอง
- ห้ามแก้ prefab หรือรัน prefab builder ถ้าผู้ใช้ไม่ได้สั่งในข้อความนั้น
- ห้ามแก้สูตรสเตตหลักโดยไม่ได้รับอนุมัติ
- หลาย session ใช้ checkout เดียวกัน ก่อน commit ให้เลือกเฉพาะไฟล์ของงานนั้น
- ไฟล์เอกสารอยู่ใน `Docs/` เท่านั้น ห้ามสร้าง `.md` ใน `Assets/`
