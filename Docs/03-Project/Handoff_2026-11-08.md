# Handoff งาน Pale Vertica (2026-11-08, อัปเดตล่าสุด)

สรุปงานที่ยังเปิดค้าง ถ้าไม่ได้เขียนว่ายืนยันแล้ว ให้ถือว่ายังไม่ได้ทดสอบ แผนงานหลักอยู่ที่ `Docs/03-Project/Action_Plan_2026-11-08.md`

## สถานะรวม

- **Git:** งาน Pale Vertica อยู่บน `main` และ push ขึ้น GitHub แล้ว
- **Submodule:** `Assets/ThirdParty/MapLab` และ `Packages/com.globalvisualizer.core` หลัง clone ให้รัน `git submodule update --init`
- **MapLab:** commit ในโฟลเดอร์ของมันเอง แล้วอัปเดตตัวชี้ใน Pale Vertica
- **Unity MCP:** เลิกใช้แล้ว ถอด `com.unity.ai.assistant` ออกแล้ว เวลา Unity เปิดอยู่ให้แก้ไฟล์บนดิสก์ แล้วให้ผู้ใช้กด Refresh, รันเทสต์ และเช็ก Play mode เอง
- **Action Plan:** Phase A ถึง D ติ๊กแล้วตามที่ผู้ใช้ยืนยันว่าผ่าน Phase E ยังไม่เริ่ม

## ยืนยันใน Unity แล้ว

ผู้ใช้ยืนยันแล้วว่าผ่าน: Game Data Workbench ทุกแท็บ, Inspector ของ MapLab Map, สีไอคอนและ backplate ของ Hotbar, error relay หาย, `LoadingManager.LoadScene` ตอนเข้า Portal และ error `OnPreCull` หาย

ยังไม่ได้ไล่เช็กแยกทีละตัว: ASPD, DoubleAttack/DoubleSpell, Echo, Fire Bolt และ indicator (ผ่านรวมในการทดสอบ)

## งานถัดไป

- ระบบเควสต์ยังไม่มี D2 จึงผ่านแบบไม่มีขั้นรับเควสต์
- Phase E: ผลิตคอนเทนต์ตาม Action Plan
- ตัวเลข HealHP/HealMP ของ Consumable, ค่าสกิล และมอนสเตอร์ Skeletom Archer/Captain เป็นค่าชั่วคราว ปรับได้ใน Game Data Workbench
- Summon Valkyrie ใช้โมเดลชั่วคราว (`Ally.prefab`) รอเปลี่ยน art
- Drop ใช้ prefab จุดชั่วคราว ตั้งค่าได้ใน `Resources/Loot/LootVisualSettings.asset`

## ข้อควรระวังเวลาทำต่อ

- อ่าน `AGENTS.md` และ `.claude/skills/pale-vertica-dev/SKILL.md` ก่อนแก้ script
- ห้าม commit หรือ push ถ้าผู้ใช้ไม่ได้สั่ง
- ห้ามแก้ prefab หรือรัน prefab builder ถ้าผู้ใช้ไม่ได้สั่งในข้อความนั้น
- ห้ามแก้สูตรสเตตหลักโดยไม่ได้รับอนุมัติ
- ก่อนกด Save ใน Game Data Workbench ให้ปิดแล้วเปิดหน้าต่างใหม่ ถ้าข้อมูล JSON เพิ่งถูกแก้จากภายนอก
- เปลี่ยนฉากด้วย `LoadingManager.LoadScene` เท่านั้น
- ไฟล์เอกสารอยู่ใน `Docs/` เท่านั้น ห้ามสร้าง `.md` ใน `Assets/`
