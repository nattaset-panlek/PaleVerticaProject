## ยังไม่มีการยืนยันใน Unity

- Game Data Workbench แบบ 1+3: เปิดครบทุกแท็บแล้วไม่มี error
- Inspector ของ MapLab Map: เลือกแผนที่แล้วไม่ค้าง
- สีไอคอนและ backplate ของ Hotbar
- error relay `connection.state_change` หายหลังถอด package
- `LoadingManager.LoadScene` ตอนเข้า Portal
- error `OnPreCull` หายหลังแก้ `MapLabChunkStreamer`
- ASPD, DoubleAttack/DoubleSpell, Echo, Fire Bolt และ indicator: ผ่านรวมในการทดสอบ แต่ยังไม่ได้ไล่เช็กทีละตัว
