# Extruded Shape Walkthrough (TH)

เครื่องมือของ MapLab สำหรับทำพื้นที่ยกสูงและพื้นที่แบน ลากจุดเป็นรอยเท้าบนพื้น (footprint) ตั้งความสูง แล้วระบบจะยกด้านบนขึ้นและสร้างกำแพงด้านที่หันเข้ากล้องให้เอง ใช้ได้ทั้งที่ราบสูง หินถ้ำ กำแพงล้อม กล่อง (เสา ลัง) และพื้นแบน (ลาน ทางแยก)

- อัปเดต: 2026-10-28 (เพิ่มข้อ 4.2 สร้าง 2D collider / mesh จากรูป)
- โค้ด: `Assets/ThirdParty/MapLab/Runtime/Shapes/` (`PointShape`, `ExtrudedShape`, `ExtrudeFormula`, `ShapeMeshData`, `ExtrudeTypes`), shader `Runtime/Shaders/MapLabShapeLit.shader`, Editor `PointShapeEditor`, `ExtrudedShapeTool`, `ShapePointHandles`, `ExtrudedShapeMenu`, `ExtrudedShapeOutlines` (ข้อ 4.2), เทสต์ `Tests/Editor/ExtrudedShapeOutlineTests.cs`
- เส้นทาง (ถนน) ใช้ [Path_Shape_Walkthrough_TH.md](./Path_Shape_Walkthrough_TH.md)
- ภาพรวมโมดูล: [Map_Lab_Walkthrough_TH.md](./Map_Lab_Walkthrough_TH.md)

## 1. สามแบบ + กล่อง + พื้นแบน

| แบบ | ด้านบน | กำแพง | ใช้กับ |
|---|---|---|---|
| **Plateau** | เต็มทั้งรูป (Top Texture x Top Color) + ขอบ lip สีอ่อน | ขอบนอกด้านที่หันเข้ากล้อง | ที่ราบสูง เนิน แท่น |
| **Void** | ขอบกว้าง Rim Width + ข้างในสี Void (ดำ) | ขอบนอกเท่านั้น | ถ้ำ ดันเจี้ยน หินทึบ |
| **Ring** | แถบกว้าง Rim Width ข้างในเปิดโล่งเห็นพื้น | ขอบนอก **และ** ขอบในฝั่งเหนือ | กำแพงล้อมลาน ห้อง |
| Box | Plateau ที่จุดทั้ง 4 เป็นมุมหัก (sharp) | ด้านหน้า | เสา ลัง บล็อก |
| พื้นแบน | Plateau ที่ Height = 0, ปิด Y Sort และ Collision | ไม่มี | ลานหิน ทางแยก พื้นทาสี |
| ขั้นบันได (Tier) | shape ที่เป็นลูกของ shape อื่น ยืนบนด้านบนของแม่ | ห้อยจากขอบของมันลงถึงด้านบนของแม่ | ที่ราบหลายชั้น ภูเขาเป็นขั้น แท่นซ้อน |

สีในแบบร่าง: แดง = ด้านบน, น้ำเงิน = กำแพง, ดำ = โพรงของ Void

## 2. เปิดที่ไหน

| ทำอะไร | ที่ไหน |
|---|---|
| สร้างรูปใหม่ | Hierarchy คลิกขวา หรือเมนู **GameObject > MapLab > Plateau Shape / Void Shape (cave rock) / Ring Shape (walled area) / Box Shape** |
| แก้จุด | เลือก object แล้วกดปุ่ม **Edit Points** (มีไอคอน) บนสุดของ Inspector หรือเลือกเครื่องมือที่มีไอคอนเดียวกันใน Tools overlay ของ Scene view เหมือน Edit Spline ของ SpriteShape |
| สร้าง GameObject 2D ที่มี Edge Collider 2D, Polygon Collider 2D หรือ Mesh ตามรูป | Inspector กล่อง **2D Shape From '<ชื่อ>'** (ข้อ 4.2) |
| เพิ่มขั้นบันได | ปุ่ม **Add Tier On Top** ใน Inspector (สร้างลูกที่หดเข้า 62% และขยับไปทางเหนือเล็กน้อย) หรือลาก shape ไปเป็นลูกของอีกอันใน Hierarchy |
| ปรับค่า | Inspector ของ **ExtrudedShape** |
| ตัวอย่าง | ฉาก demo `Assets/ThirdParty/MapLab/Demo/MapLab_Demo.unity` ใต้ `[MapLab] Environment/Shapes` และ `Ground` |

## 3. ค่าใน Inspector

| ช่อง | ความหมาย |
|---|---|
| Smoothness | จำนวนจุดย่อยต่อช่วงที่โค้ง (ช่วงที่ปลายทั้งสองเป็นมุมหักใช้เส้นตรงเส้นเดียว) |
| Type | Plateau / Void / Ring |
| Height | slider ความสูง: **ด้านบนลอยขึ้น** จาก footprint กี่หน่วย ฐานกำแพงอยู่ที่ footprint เสมอ (0 ถึง 8, 0 = พื้นแบน) |
| Rim Width | ความกว้างขอบบน (Void) หรือความหนากำแพงล้อม (Ring) |
| Border Width / Border Color | แถบขอบด้านบนตามเส้นรอบรูป (lip ของที่ราบสูง ขอบหินของลาน) 0 = ไม่มี |
| Top Color / Wall Color / Void Color | สีของแต่ละส่วน (คูณกับ texture) |
| Top Texture / Top Texture Size | ลายด้านบน ยึดกับ footprint (ไม่เลื่อนตามความสูง) ขนาด 1 รอบเป็นหน่วยโลก |
| Wall Texture / Wall Texture Size | ลายกำแพง ไล่ตามความยาวเส้นโค้ง |
| Material | `Runtime/Materials/MapLab_ShapeLit.mat` (shader `MapLab/Shape Lit`) |
| Sorting Order | ลำดับการวาด ถ้าเปิด Y Sort ต้อง **เท่ากับ order ของตัวละคร** (Pale Vertica = 6) |
| Y Sort | เปิด: แบ่งรูปเป็นแถบตามแนว Y แล้วเรียงกับตัวละครตามจุดบนพื้น ปิด: วาดเป็นชิ้นเดียวที่ order นี้ (ใช้กับพื้นแบน) |
| Sort Slice | ความสูงของแต่ละแถบบน footprint (ยิ่งเล็กยิ่งแม่น ใช้ renderer มากขึ้น) |
| Actor Height | ความสูงของตัวละครหรือพร็อพที่สูงที่สุดที่ยืนข้างรูปนี้ (ค่าเริ่ม 1.2, ตัวละคร Pale Vertica สูงราว 0.87) ถ้าด้านบนสูงกว่าค่านี้ ด้านบนจะเป็น **ชิ้นเดียว** เหลือตัดแถบเฉพาะกำแพง ขั้นบน (Tier) ใช้ค่าของชั้นล่างสุดและซ่อนช่องนี้ไว้ |
| Walk On Top | (2026-10-24, ขั้น P0 ของ [MapLab_Elevation_Proposal_TH.md](./MapLab_Elevation_Proposal_TH.md)) ตัวละครยืนบนด้านบนของรูปนี้ได้ ด้านบนจึง **ตัดแถบเสมอ** ไม่รวมเป็นชิ้นเดียว และขั้นบน (Tier) ที่ยืนบนรูปนี้ก็ตัดแถบด้วย (นับ Actor Height จากด้านบนของรูปนี้แทนพื้น) ยังไม่เปลี่ยน collider หรือไฟล์ walkable ตัวละครบนด้านบนต้องเลื่อนจุดเรียงลง `SurfaceSortBias` (= Sort Slice + 0.01) ดู [MapLab_Elevation_Walkthrough_TH.md](./MapLab_Elevation_Walkthrough_TH.md) Void ใช้ไม่ได้ ค่าเริ่มปิด |
| Ramps (ใต้รายการ Tier) | (P2) รายชื่อทางลาดของรูปนี้พร้อมปุ่ม Select และปุ่ม **Add Ramp: Click an Edge** ที่เปิดโหมด Edit Points ให้คลิกขอบเพื่อวางทางลาดหรือบันได ดู [MapLab_Elevation_Walkthrough_TH.md](./MapLab_Elevation_Walkthrough_TH.md) หัวข้อ 2 |
| Cast Shadow | เปิด/ปิดเงา (รูปที่ Height = 0 ไม่มีเงาเสมอ) |
| Shadow Color | สีและความเข้มของเงา (alpha คือความเข้มที่โคนเงา ค่าเริ่ม ดำ 0.22 เท่ากับเงาพร็อพ) |
| Shadow Direction | ทิศที่เงาทอดไปบนพื้น ค่าเริ่ม (1, -0.25) = ไปทางขวาและลงล่างนิดหน่อย ทิศเดียวกับเงาพร็อพใน demo ควรตั้งเท่ากันทุกรูปในแมพ |
| Shadow Length | ความยาวเงาต่อความสูง 1 หน่วย (0.45 = รูปสูง 2 ทอดเงา 0.9) |
| Shadow Order | order ของเงาบนพื้น ต้อง **ต่ำกว่าตัวละคร** และสูงกว่าพื้น/ถนน (ค่าเริ่ม 1 เท่ากับเงาพร็อพ) ขั้นบนไม่ใช้ช่องนี้ |
| Generate Collision | สร้าง collider ตาม footprint |

## 3.1 เงา (flat card)

- เงาเป็น **การ์ดแบน**: สีเดียวเรียบ ขอบคม ไม่มีไล่สี คือรอยเท้าของรูปที่ถูกลากไปตาม `cast = Shadow Direction (normalized) x Shadow Length x Height` เหมือนเงาของแท่งปริซึมที่ตกบนพื้น
- สร้างเฉพาะส่วนที่มองเห็น: ขอบ footprint ที่หันหนีแสง (normal · cast > 0) แต่ละเส้นได้สี่เหลี่ยมด้านขนาน 1 ชิ้น (ขอบเดิม → ขอบที่เลื่อนไป) ส่วนที่อยู่ใต้ตัวรูปไม่ต้องวาดเพราะรูปบังอยู่แล้ว ราคา 4 vertex ต่อขอบที่ทอดเงา
- **รูปบนพื้น** ได้ลูก `Shadow` 1 ชิ้น (MeshRenderer ที่ Shadow Order ไม่ใช้ SortingGroup) ตัวละครยืนบนเงาได้ และรูปวาดทับเงาของตัวเอง
- **Ring** ทอดเงาทั้งรอบนอก และเข้าไปในลาน (กำแพงฝั่งตะวันตกทอดเงาไปทางขวาบนพื้นลาน)
- **ขั้นบน (Tier)** ทอดเงาลงบน *ด้านบนของแม่* ที่ความสูงของแม่ และหยุดที่ขอบของแม่ (ไม่ห้อยกลางอากาศ) เงานี้อยู่ใน piece เดียวกับขั้น จึงไม่เพิ่ม draw call ขั้นที่ยังตัดแถบ (แม่เตี้ยกว่า Actor Height) ไม่มีเงา
- ราคา: รูปบนพื้นละ 1 draw call, ขั้นบน 0
- รูปเว้าที่มีสองส่วนเรียงกันตามทิศแสงใกล้กว่าความยาวเงา เงาสองชิ้นจะซ้อนกันและเข้มขึ้นตรงที่ซ้อน (ไม่ได้ตัดส่วนซ้อนออก เพื่อให้ถูก)

## 4. ขั้นตอน

1. สร้างรูปจากเมนู แล้วกด **Edit Points**
2. ใน Scene view: ลากลูกศร/สี่เหลี่ยม **Move all points** ที่กลางรูปเพื่อย้ายทั้งรูป (ไม่ขยับ pivot หรือ Position, ขั้นบนย้ายตามด้วย), ลากสี่เหลี่ยมสีขาวเพื่อย้ายจุด, คลิกจุดสีเขียวเพื่อเพิ่มจุด, **Shift** + คลิกเพื่อลบจุด (ต้องเหลืออย่างน้อย 3), **Ctrl/Cmd** + คลิกเพื่อสลับจุดโค้ง (สี่เหลี่ยมโปร่ง) กับมุมหัก (สี่เหลี่ยมทึบ)
3. ลาก **Height** ด้านบนลอยขึ้นและกำแพงยืดขึ้นตาม ฐานอยู่ที่เดิม
4. เลือก Type, สี, texture
5. กด Edit Points อีกครั้งเพื่อออกจากโหมดแก้จุด
6. ถ้าแมพมี **MapLabMap** ให้กด **Bake Walkable Area** ใหม่

## 4.1 ซ้อนหลายขั้น (Tier)

1. เลือกที่ราบชั้นล่าง กด **Add Tier On Top** จะได้ `Tier 2` เป็นลูก
2. เลือก `Tier 2` แล้ว Edit Points / ปรับ Height ตามต้องการ กด Add Tier On Top อีกครั้งเพื่อได้ `Tier 3`
3. Inspector มีกล่อง **Tiers** บอกว่ารูปนี้มีกี่ชั้น (เช่น "Tiers: 3 layers, 2 on top of 'Plateau'") แล้วไล่ทุกชั้นจากบนลงล่าง: ชื่อชั้น (Tier 1 (ground), Tier 2, ...) ความสูงฐานถึงด้านบน และปุ่ม **Select** เพื่อกระโดดไปแก้ชั้นนั้น ชั้นที่กำลังแก้เป็นตัวหนาและปุ่มเป็น **Editing** ชั้นที่แยกเป็นสองกองบนชั้นเดียวกันจะเยื้องเท่ากัน
4. ปุ่ม Add Tier On Top บอกชื่อชั้นที่จะวางทับ (เช่น Add Tier On Top of 'Tier 2') และใต้กล่องบอกว่าชั้นนี้วาดแบบไหน (`one piece`, `one top piece + wall bands` หรือ `bands`)
5. ใน MapLab Window แถวของที่ราบที่มีชั้นบนมีลูกศรพับ/กาง ชั้นบนแสดงเป็นแถวเยื้องใต้ที่ราบ (Tier 2, Tier 3 พร้อมความสูงด้านบน) คลิกแถวเพื่อเลือกชั้นนั้นมาแก้ ปุ่มเป้าเพื่อหาตำแหน่ง และคอลัมน์ Type ของที่ราบบอกจำนวน เช่น "Plateau, 2 tiers on top"

กติกาของขั้น:

- ฐานของขั้น = ด้านบนของแม่ (สูงสะสมขึ้นไปทุกชั้น) เปลี่ยน Height ของแม่แล้วทุกขั้นข้างบนลอยตามเอง
- ขั้นบน **ไม่มี collider** เพราะลอยอยู่ ไม่แตะพื้น collider ของทั้งกองคือ footprint ของชั้นล่างสุด
- ขั้นที่ฐานสูงกว่า Actor Height (ปกติทุกขั้นที่ยืนบนที่ราบสูง) วาดเป็น **ชิ้นเดียว** ทั้งกำแพงและด้านบน จุดเรียงอยู่หน้าด้านบนของแม่ 0.01 จึงวาดทับแม่ทั้งรูปเสมอ ขั้นถัดไปก็อยู่หน้าขั้นก่อน 0.01 ต่อกันไป
- ขั้นที่ฐานต่ำกว่า Actor Height (แม่เตี้ย) ยังตัดเป็นแถบ และถูกเลื่อนจุดเรียงลงมาเท่ากับ Sort Slice ของแม่ (+0.01) ทำให้วาดทับแถบด้านบนของแม่ที่อยู่ใต้มัน ส่วนกำแพงใช้ y ต่ำสุดของฐานในแถบ
- footprint ของขั้นควรอยู่ข้างในขอบของแม่ ถ้ายื่นออก ส่วนที่ยื่นจะลอยกลางอากาศ

## 4.2 สร้าง 2D collider หรือ mesh ตามรูป

ใช้ตอนอยากได้ object แยกที่มีรูปทรงเดียวกับ Plateau เช่น:
- เส้นขอบกันตก (Edge Collider 2D)
- trigger เขตพื้นที่ (Polygon Collider 2D)
- mesh แบนไว้ทำ mask หรือ effect

**ขั้นตอน**

1. เลือก Plateau, Void, Ring หรือ Tier (เลือกหลายอันพร้อมกันได้)
2. เลื่อน Inspector ลงไปที่กล่อง **2D Shape From '<ชื่อ>'** (อยู่ใต้กล่อง Tiers)
3. ช่อง **Make** เลือกชนิด:

   | Make | ได้อะไร |
   |---|---|
   | Edge Collider 2D | เส้นปิดตามขอบรูป จุดแรกต่อกลับมาที่จุดสุดท้าย Ring ได้สองเส้น คือขอบนอกและขอบใน |
   | Polygon Collider 2D | collider เต็มรูป Ring ได้สอง path และรูตรงกลางยังเปิด |
   | Mesh | MeshFilter + MeshRenderer แบนเต็มรูป (Ring เป็นแถบ) ใช้ material `Sprites-Default` ที่ sorting layer และ order เดียวกับรูป |

4. ช่อง **From** เลือกเส้น:
   - **Ground outline**: เส้นที่กำแพงแตะพื้น ตรงกับ collider ของรูปเอง สำหรับ Tier คือด้านบนของชั้นที่มันยืน
   - **Top outline**: ด้านบนของรูป ลอยขึ้นตาม Height
5. กด **Create Edge Collider 2D** (ชื่อปุ่มเปลี่ยนตามที่เลือก)

**ผลที่ได้**
- GameObject ใหม่ชื่อ `<ชื่อรูป> Edge`, `<ชื่อรูป> Collider` หรือ `<ชื่อรูป> Mesh` วางอยู่ถัดจากรูป (parent เดียวกัน, position, rotation, scale เดียวกัน, layer เดียวกัน)
- object ใหม่ถูกเลือกไว้ให้ และ Ctrl+Z ลบได้
- Mesh ที่ได้ถูกบันทึกเป็นไฟล์ `<ฉาก>_MapLab/<แมพ>/Outlines/<ชื่อ>.asset` เพื่อให้ทำ prefab ได้ (ถ้ารูปไม่อยู่ใต้ MapLabMap หรือยังไม่ได้ save ฉาก mesh จะอยู่ในฉาก)

**ข้อควรรู้**
- object ที่ได้เป็นสำเนา ไม่ตามรูปเมื่อแก้จุดหรือความสูง ถ้าแก้รูปแล้ว ให้ลบอันเก่าแล้วกดสร้างใหม่
- ค่า Make และ From ที่เลือกล่าสุดจำไว้ในเครื่องนั้น
- collider ที่สร้างใต้ MapLabMap จะนับเป็นสิ่งกีดขวางตอน Bake Walkable area ด้วย ถ้าไม่ต้องการ ให้ติ๊ก Is Trigger หรือย้ายออกจากแมพ

## 5. วิธีคำนวณ

```
footprint (เส้นที่ลาก, ทวนเข็ม)        = รอยบนพื้น = collider
ด้านบน = footprint + (0, Height)          = สิ่งที่เห็นข้างบน
กำแพง = ช่วงของ footprint ที่ normal หันลง (หันเข้ากล้อง)
         แต่ละช่วง: จากขอบ footprint ขึ้นไปถึงขอบด้านบน
         จุดเริ่ม/จบ = ตรงที่เส้นโค้งหักเป็นแนวตั้ง
```

- **ลายกำแพงตามความโค้ง**: U = ระยะตามเส้นขอบ, V = ระยะจากขอบบนลงมา แนวก้อนอิฐโค้งตามขอบ รอยต่อแนวตั้งตั้งตรง
- **แรเงา**: ตามทิศที่ผนังหัน ฐานมืดกว่าขอบบน 16% ที่มุมหัก (ทิศเปลี่ยนเกิน 30 องศา) แรเงาไม่ถูกเกลี่ย จึงเห็นเหลี่ยมคม
- **Collider = footprint**: เดินอ้อมไปด้านหลังที่สูงได้ ส่วนที่ลอยขึ้น (ด้านบนและกำแพง) เป็นภาพเท่านั้น Ring มีรูตรงกลาง ลานข้างในเดินได้ทั้งหมด
- **Y Sort ตามพื้น**: รูปถูกตัดเป็นแถบตามแนว Y ของ footprint ทุกแถบเป็น SortingGroup ที่ order เดียวกับตัวละคร ตำแหน่งที่ใช้เรียงคือจุดบนพื้น: ชิ้นกำแพงใช้ y สูงสุดของฐานในแถบ ชิ้นด้านบนใช้ y ต่ำสุดของ footprint ในแถบ ผลคือ
  - ตัวละครที่ยืนด้านหลัง (เหนือ footprint) ถูกที่สูงบัง
  - ตัวละครที่ยืนหน้ากำแพงอยู่หน้ากำแพง
  - ตัวละครในลาน Ring อยู่หน้ากำแพงฝั่งเหนือ และอยู่หลังขอบฝั่งใต้
- **ด้านบนที่สูงกว่าตัวละครเป็นชิ้นเดียว**: ด้านบนวาดอยู่ที่ footprint + ความสูง ส่วนของด้านบนที่ควรอยู่ *หลัง* ตัวละคร (footprint เหนือเท้าตัวละคร) จะถูกวาดสูงกว่าหัวตัวละครเสมอเมื่อความสูงมากกว่าตัวละคร จึงไม่มีทางทับกัน ด้านบนทั้งรูปจึงเรียงที่ขอบหน้า (y ต่ำสุดของ footprint) ได้ชิ้นเดียว และวาดหน้ากำแพงของตัวเองทุกแถบ (กำแพงไม่เคยต้องทับด้านบนของรูปเดียวกัน) ส่วนกำแพงยังต้องตัดแถบ เพราะฐานกำแพงอยู่ระดับเดียวกับตัวละคร
  - เงื่อนไข: `ความสูงของด้านบน >= Actor Height` → ด้านบน 1 ชิ้น / `ความสูงของฐาน >= Actor Height` (ขั้นบน) → ทั้งรูป 1 ชิ้น / ไม่อย่างนั้นตัดแถบทั้งคู่เหมือนเดิม
- **ขอบ lip และโพรงดำอยู่ใน draw call เดียวกับด้านบน**: shader `MapLab/Shape Lit` อ่าน UV ช่อง 1 (x = 1 คือสีเรียบ ไม่ใช้ลาย, 0 คือใช้ลาย) แต่ละชิ้นจึงมีแค่ 2 submesh: กำแพง (ลายกำแพง) กับด้านบน (ลายด้านบน + สีเรียบ) ลำดับในชิ้นด้านบนคือ โพรงดำ → ด้านบน/ขอบ Rim → lip ทับข้างบนสุด mesh ทุกอันที่ใช้ shader นี้ต้องเขียน UV ช่อง 1 เอง (Path Shape เขียน 0 ทั้งหมด) ถ้าไม่เขียน Unity เติมค่าเองและภาพจะกลายเป็นสีเรียบไม่มีลาย (เจอมาแล้วตอนทดสอบ ถนนเป็นสีขาว)
- **จุดเรียงอยู่ตรงกลาง bounds ของชิ้นเสมอ**: mesh ของแต่ละชิ้นตั้ง bounds ให้จุดกึ่งกลาง (แนว y) อยู่ที่จุดเรียงพอดี (ยังครอบทุก vertex ไว้ใช้ culling) จึงเรียงถูกไม่ว่า Unity จะใช้ตำแหน่ง transform หรือกึ่งกลาง bounds ก็ตาม (ตรวจแล้วว่าถ้าไม่ทำ ขั้นบนจะถูกแถบด้านบนของแม่ทับเป็นขั้นๆ)
- **order ของ renderer ในชิ้น = order ของ SortingGroup เสมอ** (เช่น 6 ทั้งคู่) ตรวจแล้วใน Unity 6000.4 + URP 2D ว่าเวลาเทียบ SortingGroup กับ renderer ที่อยู่นอกกลุ่ม (เช่นเงาที่ order 1) Unity ใช้ order ของ renderer ข้างในด้วย ถ้า renderer ในชิ้นเป็น 0 เงาที่ order 1 ถึง 5 จะถูกวาดทับรูป ทำให้รูปดูโปร่งเห็นเส้นขอบของชั้นล่างทะลุขึ้นมา และตัวละครที่ order 6 ก็จะวาดทับรูปได้ด้วย
- **ต้องตั้ง Transparency Sort Mode = Custom Axis (0, 1, 0)** ใน Renderer2D (Pale Vertica ตั้งแล้ว)

## 6. ผลที่ควรได้

ลูกที่ระบบสร้างเอง (ไม่ถูก save ลงฉาก สร้างใหม่ทุกครั้งที่เปิดฉากหรือเริ่มเล่น แก้ด้วยมือไม่ได้ คลิกใน Scene view จะเลือกตัวรูปให้):

```
Plateau (ExtrudedShape)
  Visual
    Piece 000 ...   SortingGroup (order 6) + MeshRenderer 2 submesh: กำแพง, ด้านบน (รวม lip และโพรงดำ)
                    Plateau สูง: 1 ชิ้นด้านบน + 1 ชิ้นต่อแถบที่มีกำแพง / Tier: 1 ชิ้นรวมทั้งหมด (เงาบนแม่อยู่ต้น submesh กำแพง)
  Shadow            MeshRenderer ที่ Shadow Order (เฉพาะรูปบนพื้นที่ Height > 0 และเปิด Cast Shadow)
  Collision         PolygonCollider2D ตาม footprint (Ring มี path ที่ 2 เป็นรู)
```

ฉาก demo: Plateau 3 ขั้น (Plateau สูง 1.75 → Tier 2 สูง 1.25 → Tier 3 สูง 1), Void Rock, Ring Wall, เสา Box 4 ต้น (order 6, Y Sort) และ Junction, Plaza (Height 0, ปิด Y Sort และ Collision)

## 7. ข้อจำกัด

| เรื่อง | สถานะ |
|---|---|
| หมุนหรือย่อขยาย object | ยังไม่รองรับ ให้ Rotation = 0, Scale = 1 (ย้ายตำแหน่งได้) |
| เดินขึ้นไปบนที่สูง / ทางลาด | ยังไม่มี |
| รูปเว้าลึกมาก (เช่นรูปตัว U หันลง) | การเรียงตาม Y ใช้แถบละ 1 จุดเรียง ตัวละครที่ยืนในร่องแคบอาจเรียงผิดเล็กน้อย ลด Sort Slice ช่วยได้ |
| ทางเข้า Ring | เป็นวงปิด ยังเปิดช่องประตูไม่ได้ |
| ตัวละครที่ถูกที่สูงบัง | ยังไม่มีการทำให้จางแบบใบไม้ |
| จำนวน draw call | 1 ต่อชิ้น (ชิ้นกำแพง 1 ต่อแถบที่มีกำแพง + ด้านบน 1 ชิ้นถ้าสูงกว่า Actor Height) ตัวเลขวัดจริงดู [MapLab_Performance_TH.md](./MapLab_Performance_TH.md) |
| พร็อพสูงกว่า Actor Height ที่ยืนในร่องเว้าของรูป | ด้านบนชิ้นเดียวอาจทับส่วนบนของพร็อพผิด ให้เพิ่ม Actor Height ของรูปนั้นให้สูงกว่าพร็อพ (ด้านบนจะกลับไปตัดแถบ) |

## 8. ข้อผิดพลาดที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| มองไม่เห็นรูป | ไม่มี Material ให้ใส่ `MapLab_ShapeLit.mat` |
| ตัวละครเดินทับที่สูงหรือหายใต้ที่สูงตลอด | Sorting Order ไม่เท่ากับของตัวละคร หรือ Renderer2D ไม่ได้ตั้ง Custom Axis |
| ลาน/ทางแยกบังตัวละคร | พื้นแบนต้องปิด Y Sort และตั้ง order ต่ำกว่าตัวละคร |
| หัวของตัวละครตัวใหญ่ (บอส) ถูกด้านบนของรูปเตี้ยๆ ทับตอนยืนข้างหลัง | Actor Height ต่ำกว่าตัวละครนั้น ตั้งให้เท่ากับตัวที่สูงที่สุดที่เดินแถวนั้น |
| ขอบ lip เป็นลายแทนสีเรียบ | material ไม่ได้ใช้ shader `MapLab/Shape Lit` ตัวใหม่ หรือ shader ยัง compile ไม่เสร็จ |
| เงาทับตัวละคร | Shadow Order สูงกว่าหรือเท่ากับ order ของตัวละคร ตั้งให้ต่ำกว่า |
| รูปหรือขั้นบนดูโปร่ง เห็นเส้นขอบชั้นล่างทะลุ | renderer ในชิ้นมี order ไม่เท่ากับ SortingGroup (โค้ดเก่า) กด Rebuild หรือเปิดฉากใหม่ ระบบจะตั้งให้เท่ากัน |
| เงาหายใต้ถนนหรือลาน | Shadow Order ต่ำกว่า order ของถนน/ลาน (demo: ถนน -92, ลาน -90) |
| เงาของแต่ละรูปไปคนละทิศ | Shadow Direction ไม่เท่ากัน เลือกหลายรูปแล้วตั้งพร้อมกันใน Inspector |
| ขั้นบนไม่มีเงา | แม่เตี้ยกว่า Actor Height ขั้นนั้นจึงยังตัดแถบ (ดูข้อ 4.1) หรือปิด Cast Shadow ไว้ |
| ลาน/ทางแยกขวางทางเดิน | ปิด Generate Collision |
| ขอบ Void / Ring / Border เป็นหนาม | Rim/Border กว้างกว่าโค้งที่แคบที่สุด ลดความกว้างหรือเพิ่มจุด |
| ปุ่ม Edit Points ไม่มีไอคอน | ไฟล์ไอคอนหายหรือยังไม่ได้ตั้งค่า: **Tools > MapLab > Developer > Apply Icons** ([MapLab_Icons_Walkthrough_TH.md](./MapLab_Icons_Walkthrough_TH.md)) |
| ขั้นบนถูกแม่ทับเป็นขั้นๆ | mesh ของชิ้นถูกสร้างจากเวอร์ชันเก่า (ก่อนตั้ง bounds ตามจุดเรียง) กด Rebuild ที่ชั้นล่างสุด |
| ขั้นบนไม่ลอยตามเมื่อแก้ความสูงแม่ | ขั้นไม่ได้เป็นลูกโดยตรงของแม่ (มี GameObject อื่นคั่น) |
| มีลูกชื่อ `Walls` / `Top` ค้างจากเวอร์ชันก่อน | ระบบลบให้เองตอน Rebuild |
| แก้รูปแล้ว NavMesh/AI ยังเดินแบบเดิม | ยังไม่ได้ Bake Walkable Area ใหม่ |
| Edge / Collider / Mesh ที่สร้างไว้ไม่ตรงกับรูปแล้ว | เป็นสำเนา ณ ตอนกด ลบแล้วกดสร้างใหม่ (ข้อ 4.2) |
| Mesh ที่สร้างมองไม่เห็น | sorting order ต่ำกว่าพื้นหรือ object อื่นบัง ปรับ Order in Layer ของ MeshRenderer |
