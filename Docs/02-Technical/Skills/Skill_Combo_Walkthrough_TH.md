# ระบบ Skill Chain & Combo System

ระบบนี้ช่วยให้สกิลสามารถเปลี่ยนรูป (Mutate) กลายเป็นสกิลใหม่ได้ เมื่อตัวละครมีสถานะ (Buff) ตามที่กำหนดไว้ เช่น ระบบคอมโบแบบ **Final Fantasy XIV** ที่สกิล A ส่งผลให้เกิดสกิล B

---

## 1. วิธีตั้งค่าสกิลคอมโบใน Unity (Inspector)

ระบบคอมโบนี้ถูกฝังรวมอยู่ใน **ActiveSkill** (ScriptableObject) โดยไม่ต้องเขียนโค้ดเพิ่ม แค่คลิกตั้งค่าใน Inspector:

1. เปิดไฟล์ `ActiveSkill` ที่ต้องการให้เป็นจุดเริ่มต้น (เช่น สกิลฟันดาบปกติ)
2. เลื่อนหาหมวด **[Skill Chain & Combo]**
3. เพิ่มข้อมูลในลิสต์ `Chain Overrides`:
   - `Required Buff Name`: ชื่อของ Buff ที่เป็นเงื่อนไข เช่น `Astral Rift I`
   - `Replacement Skill`: ลากไฟล์ ActiveSkill อันใหม่ที่ต้องการให้มาแทนที่ใส่ช่องนี้
   - `Consume Buff On Cast`: ติ๊กถูก ✔️ เพื่อให้ลบบัฟเงื่อนไขทิ้งทันทีที่กดร่าย (เพื่อเข้าสู่สถานะคอมโบขั้นถัดไป)

---

## 2. โครงสร้างเบื้องหลัง (Behind the Scenes)

### การประเมินสกิลแบบ Real-time (`ActiveSkill.GetActiveChainOverride`)
ระบบจะไม่เปลี่ยน Data ของสกิลดั้งเดิม แต่จะใช้การเช็คแบบ Real-time ผ่าน `BuffSystem` ของผู้ร่าย ถ้าระบบพบว่าผู้ร่ายมีบัฟตรงกับ `RequiredBuffName` ระบบจะแสดงผลและร่ายสกิลที่อยู่ใน `ReplacementSkill` แทนทันที

### การแสดงผลที่ Hotbar (`HotbarSlotView.cs`)
เมื่อระบบประเมินว่าสกิลถูกเปลี่ยนรูปแล้ว Hotbar จะอัปเดตอัตโนมัติ:
1. **เปลี่ยน Icon สกิล**: ใช้รูป Icon ของ `ReplacementSkill` แทน
2. **เปลี่ยนกรอบแสดงผล**: เปิด GameObject `_comboHintObj` เพื่อสร้างกรอบแสงดึงดูดสายตาผู้เล่น
*(คุณสามารถตั้งค่า `Combo Hint Obj` ได้โดยลาก GameObject กรอบแสงไปใส่ในหน้าต่าง Inspector ของ HotbarSlot Prefab)*

### การแยก Cooldown อิสระ (`CommandDirector.cs`)
สกิลที่กลายพันธุ์ออกมา จะถูกมองว่าเป็น **"สกิลใหม่"** 100% 
ระบบจะแยก Cooldown ออกจากสกิลดั้งเดิมอย่างอิสระ โดยใช้คลาส `SkillInstance` ตัวใหม่ ทำให้คุณสามารถออกแบบสกิลคอมโบที่มี Cooldown รุนแรงในขั้นสุดท้ายได้โดยไม่กระทบสกิลขั้นแรก

---

## 3. ขั้นตอนการนำไปใช้งานจริง (ตัวอย่าง)

1. **สร้างสกิล A (ดาบ 1)**: ตั้งค่าดาเมจ 10. ในส่วนของ `Effects` ให้ใส่ `ApplyTemporaryBuffEffect` ตั้งชื่อบัฟว่า `SwordCombo_1` (ระยะเวลา 5 วินาที)
2. **สร้างสกิล B (ดาบ 2)**: ตั้งค่าดาเมจ 20. 
3. **ผูกคอมโบ**: กลับไปที่ **สกิล A** -> ตรง `Chain Overrides` -> ตั้ง Required Buff = `SwordCombo_1` และ Replacement Skill = **สกิล B**
4. **ลากใส่ Hotbar**: ลากแค่ **สกิล A** ลง Hotbar!

**ผลลัพธ์ในเกม**:
เมื่อกดใช้สกิล A ตีศัตรู ตัวละครจะได้บัฟ `SwordCombo_1` -> ทันใดนั้นบนหน้าจอ Hotbar สกิล A จะมีกรอบสว่างขึ้นมาและเปลี่ยนรูปเป็น **สกิล B** ทันที -> เมื่อกดสกิล B บัฟจะถูกกินทิ้ง และสกิลกลับมาเป็นรูปสกิล A เหมือนเดิม!
