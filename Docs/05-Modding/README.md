# 🛠️ Modding & API Architecture

This directory outlines the structure and standards required to support user-created content (Mods) in **Realm of Hero**.

## 🏗️ Technical Foundation

### 1. Data-Driven Design
The project uses JSON-based data configuration. Modding support will leverage this by allowing mods to override or add new entries to the `Database.cs` system.

### 2. Interface-Based Logic
To support custom logic without modifying core source code, the system relies on `IEntity`, `TargetingLogic`, and `EffectLogic` interfaces. Modders can create new implementations of these to add unique skills or behaviors.
