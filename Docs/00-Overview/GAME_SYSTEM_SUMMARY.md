# Realm of Hero: Game System Summary

**Realm of Hero** เป็นเกมแนว Action RPG ที่ขับเคลื่อนด้วยระบบ Data-Driven อย่างเต็มรูปแบบ (JSON-Based) ผู้เล่นสามารถพัฒนาตัวละครผ่านระบบที่ซับซ้อนและยืดหยุ่น ทั้งในด้านสเตตัส อุปกรณ์สวมใส่ และผังสกิลขนาดใหญ่

---

## 1. ระบบตัวละครและการพัฒนา (Character & Progression)

### สเตตัสและเลเวล (Attributes & Levels)
- **Base Level / Job Level**: ระบบเลเวลแยกส่วนเพื่อการพัฒนาที่แตกต่าง
- **Attribute System**: ระบบสเตตัสพื้นฐาน (STR, AGI, INT, VIT, DEX, LUK) ที่ส่งผลต่อค่าสถานะรอง (ATK, DEF, Hit, Flee, Critical ฯลฯ)
- **Experience System**: มีตาราง EXP ที่กำหนดตายตัว พร้อมแถบความคืบหน้า (EXP Bar) แสดงผลแบบ Real-time บน UI

### ผังสกิลพาสซีฟ (Passive Skill Tree)
- **Node-Based Progression**: ผังขนาดใหญ่ที่รวบรวมโหนดประเภทต่างๆ:
  - **Attribute Nodes**: เพิ่มสเตตัสพื้นฐาน
  - **Skill Nodes**: ปลดล็อกความสามารถใหม่
  - **Key Skills / Class Unlock**: ปลดล็อกคลาสใหม่หรือความสามารถพิเศษขั้นสูง
- **Passive Points**: แต้มที่ได้จากการเลเวลอัพเพื่อนำมาอัปเกรดโหนดในผัง

---

## 2. ระบบสกิล (Skill System)

### สกิลใช้งาน (Active Skills)
- **Dynamic Casting**: รองรับทั้ง Variable Cast Time (VCT) และ Fixed Cast Time (FCT)
- **Skill Types**:
  - **Damage/Heal**: สกิลโจมตีและฟื้นฟู
  - **Toggle Skills**: สกิลเปิด/ปิดที่ใช้มานาต่อเนื่อง (Aura)
  - **Projectiles & AOE**: สกิลยิงกระสุนและสกิลพื้นที่วงกว้าง
- **Targeting Logic**: ระบบล็อกเป้าหมายหรือเลือกพื้นที่ (Cone, Radius, Box)

### สกิลสนับสนุน (Support Skills/Modifiers)
- **Payload Modifiers**: ระบบที่สามารถปรับแต่งประสิทธิภาพของสกิลหลักได้ (เพิ่มดาเมจ, ลดมานา, เพิ่มขนาดพื้นที่)

---

## 3. ระบบไอเทมและอุปกรณ์ (Item & Equipment)

### ประเภทไอเทม (Item Categories)
- **Equipment**: หมวก, ชุดเกราะ, ถุงมือ, เครื่องราง, อาวุธ และเครื่องประดับ
- **Costume**: ชุดแฟชั่น (Head, Body, Arms, Legs) ที่แสดงผลผ่านระบบ Addressables (PSB) และสามารถมอบสเตตัสโบนัสได้
- **Fragments/Runes**: ไอเทมสำหรับติดตั้งลงใน Socket ของอุปกรณ์
- **Skill Runes**: รูนพิเศษที่มอบสกิลใหม่เมื่อติดตั้ง
- **Consumables**: ไอเทมกดใช้งานเพื่อฟื้นฟูหรือบัฟ

### การเสริมพลังอุปกรณ์ (Advancement)
- **Refinement (ตีบวก)**: เพิ่มประสิทธิภาพพื้นฐานของอุปกรณ์ตามระดับการตีบวก
- **Reforge (เสริมออปชั่น)**: เพิ่มโบนัสพิเศษแบบสอดแทรก
- **Socketing**: การเจาะรูและติดตั้ง Fragment เพื่อเพิ่มความสามารถเฉพาะทาง

### ระบบโบนัสและเงื่อนไข (Effects & Conditions)
- **Set Bonuses**: เมื่อใส่ไอเทมครบเซ็ตตามที่กำหนดจะได้รับโบนัสตามจำนวนชิ้น
- **Conditional Effects**: โบนัสที่จะทำงานเมื่อตัวละครมีสเตตัสถึงเกณฑ์ (เช่น STR >= 100)
- **Refine Conditions**: โบนัสเพิ่มเติมที่จะแสดงผลเมื่อไอเทมถูกตีบวกถึงระดับที่กำหนด (เช่น +5 จะเพิ่ม ATK 10%)

---

## 4. ระบบอินเตอร์เฟส (User Interface)

### การจัดการไอเทม (Inventory Management)
- **Grid View**: แสดงไอเทมในรูปแบบตาราง พร้อมระบบ Sorting
- **Detailed Information**: หน้าต่างแสดงข้อมูลไอเทมเชิงลึก พร้อมการ Highlight ค่าพลังและคำอธิบาย
- **Context Menu**: เมนูคลิกขวาเพื่อให้ผู้เล่นจัดการไอเทมได้รวดเร็ว (Unequip, Use, Info)

### ประสบการณ์การใช้งาน (UX Traits)
- **Hover Tooltips**: ระบบแสดงข้อมูลสรุปเมื่อนำเมาส์ไปชี้ที่ไอเทมหรือโหนดสกิล
- **Drag & Drop**: รองรับการลากไอเทมจากกระเป๋าไปใส่ในสล็อตอุปกรณ์หรือ Costume โดยตรง
- **Visual Feedback**: มีสัญลักษณ์บ่งบอกไอเทมที่สวมใส่อยู่ (Equip Icon) และการจัดการช่องสวมใส่ที่ชาญฉลาด

---

## 5. จุดเด่นของเกม (Key Features)
1. **High Customization**: ปรับแต่งตัวละครได้อิสระผ่าน Skill Tree และระบบ Socketing
2. **Visual Consistency**: ระบบ Costume ที่แยกส่วนกับการเล่นแต่ยังมอบความคุ้มค่าด้านสเตตัส
3. **Complex Mechanic, Simple Control**: แม้เบื้องหลังจะซับซ้อนด้วยสูตรคำนวณและเงื่อนไขมากมาย แต่ผู้เล่นสามารถจัดการทุกอย่างได้ผ่าน Drag & Drop และเมนูที่เข้าใจง่าย
4. **Data-Driven**: ทุกอย่างในเกมสามารถปรับสมดุลได้ง่ายผ่าน JSON ไฟล์ ทำให้การเพิ่มคอนเทนต์ใหม่ทำได้รวดเร็ว
